# INTELSYST2026 — Deep Learning for Semen Analysis in Male Infertility


It contains the supplementary files cited in the manuscript (S1–S4), the complete
retrieval and screening pipeline, and the scripts that generate every reported count
and both figures.

## What this study is, and is not

This is a **systematic literature map**, not a systematic review.

Eligibility and every charted variable were determined from **title and abstract
metadata**. Full texts were **not** retrieved, screening was performed by a **single
reviewer** with rule-based automation and no duplicate assessment, and **no critical
appraisal** was carried out. Consequently the repository supports no certainty grading
and no claim about the internal validity of any included study. Every indicator records
what a record *states in its abstract*, not a verified property of the study.

These limitations are stated in the manuscript and detailed in `supplementary/S3`.
